## Frontend Assignment 2

## Project Description

MAISON ÉLLE is a fashion and beauty website created to practice CSS Flexbox and Grid layouts.

The website has a modern and minimal design inspired by fashion brands.

## Pages

### Home
Contains the main navigation bar of the website.

### Collections
Displays three fashion collection cards:
- Everyday Elegance
- Evening Muse
- Soft Essentials

The cards are arranged using Flexbox.

### Style Guide
Uses CSS Grid to create a page layout with:
- Header
- Sidebar
- Main content
- Footer

### Gallery
Displays 9 fashion images using CSS Grid.

The gallery also includes a hover overlay effect with image titles.

### Portfolio
Combines both Flexbox and CSS Grid.

The page contains:
- Header and navigation
- Projects area
- Information sidebar
- Footer

## Technologies Used

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design

## Project Structure

- `index.html` — Home page
